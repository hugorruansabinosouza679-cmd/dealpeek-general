# DealPeek General

Curadoria de promoções e afiliados. **Peek. Buy. Smile.**

## Como colocar no ar (GitHub Pages)

1. Abra: https://github.com/hugorruansabinosouza679-cmd/dealpeek-general/settings/pages
2. Em **Source**, escolha **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Clique em **Save**
5. Espere 1–2 minutos e abra:
   **https://hugorruansabinosouza679-cmd.github.io/dealpeek-general/**

## Arquivo do site

O site é o arquivo `index.html` na raiz deste repositório.
